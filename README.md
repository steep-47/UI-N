# UI-N

面向手机端 SillyTavern 的小说阅读式界面插件。

## 功能

- 日间、夜间与跟随系统三种显示模式
- 小说式正文排版，可调字号、行距和左右留白
- 保留层数、缓存命中、思考时间与 Token 数
- 保留消息菜单和编辑按钮
- 用户消息可压缩为低干扰指令块
- 输入栏旁提供一键进入或退出阅读模式
- 不修改聊天内容，不影响编辑、滑动重生成和其他插件逻辑

## 安装

将本仓库地址粘贴到 SillyTavern 的“扩展 → 安装扩展”中。若使用压缩包，请解压到 SillyTavern 的第三方扩展目录后重启。

## 使用

点击输入栏左侧的书本按钮切换沉浸阅读。详细选项位于“扩展设置 → UI-N”。

## 兼容说明

插件读取 SillyTavern 原生的消息层数、计时和 Token 显示节点，并尝试识别包含“缓存命中”的状态节点。不同版本的 Memo-N 若使用了其他 DOM 类名，缓存数据仍可能需要一次针对性适配。
